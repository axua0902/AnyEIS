# AnyEIS 模型文件格式说明

## 概述

AnyEIS 使用 JSON 格式存储模型配置文件，支持三种模型类型：
- **ECM**: 等效电路模型 (Equivalent Circuit Model)
- **MS**: 多球壳模型 (Multi-Shell Model)
- **MT**: 多项介电模型 (Multi-Term Model)

---

## 通用字段

所有模型文件都包含以下通用字段：

| 字段 | 类型 | 说明 |
|-----|------|------|
| `version` | string | 模型文件版本号，当前为 "1.0" |
| `model_type` | string | 模型类型：ECM / MS / MT |
| `model_name` | string | 用户自定义的模型名称 |
| `file_path` | string | 关联的数据文件路径 |
| `created_date` | string | 文件创建日期，格式：YYYY-MM-DD |
| `frequency` | object | 频率范围配置 |
| `notes` | string | 备注说明信息 |

### frequency 字段结构

```json
"frequency": {
  "min": 0.1,        // 最小频率
  "max": 10000,      // 最大频率
  "points": 50,      // 频率点数
  "unit": "Hz"       // 频率单位
}
```

## ECM 模型 (等效电路模型)

### 文件位置
```
ModelFileExamples/ECM_Randles_Circuit.json
```

### 电路字符串语法

电路使用字符串表达式描述，语法规则：

| 符号 | 含义 | 示例 |
|-----|------|------|
| `R` | 电阻 | `R` |
| `C` | 电容 | `C` |
| `L` | 电感 | `L` |
| `p(...)` | 并联 | `p(R,C)` 表示 R||C |
| `(...)` | 串联 | `(R,p(R,C))` |
| `,` | 分隔符 | |

**示例电路**：
- `R` - 纯电阻
- `R,R` - 两个电阻串联
- `p(R,C)` - 电阻与电容并联
- `R(p(R,C),R)` - Rs + (Rct||Cdl) 串联

### 电路图示

```
circuit_string: "R(p(R,C),R)"

    C
   ++ ++
 ---||---
 |  R   |
 |  ||  |
 +--||--+----+
 |       R    |
 +-----------+
```

等效于：Rs + (Rct || Cdl)

### 参数字段结构

```json
"parameters": [
  {
    "name": "Rs",              // 参数名（代码中使用）
    "display_name": "Solution Resistance",  // 显示名称
    "value": 100.0,            // 初始值
    "unit": "ohm",             // 单位
    "min": 0.0,               // 最小值
    "max": 10000.0,           // 最大值
    "fixed": false             // 是否固定（不参与拟合）
  }
]
```

## MS 模型 (多球壳模型)

> **注意**: MS 模型文件目录和示例文件待实现。

MS 模型用于描述具有核-壳结构的颗粒体系的介电响应，如生物细胞、涂层颗粒等。

### 预期文件位置
```
ModelFileExamples/MS/MS_Core_Shell_TwoLayer.json
```

### 支持的内置模型类型

| 模型类型 | 代码 | 说明 |
|---------|------|------|
| Db | Debye | Debye弛豫模型 |
| CC | Cole-Cole | Cole-Cole色散模型 |
| DC | Davidson-Cole | Davidson-Cole色散模型 |
| HN | Havriliak-Negami | HN色散模型 |

### 模型公式

**Debye 模型**:
```
ε(ω) = εh + Δε / (1 + jωτ)
```
- `εh`: 高频介电常数
- `Δε`: 弛豫强度 (εl - εh)
- `τ`: 弛豫时间

**Cole-Cole 模型**:
```
ε(ω) = εh + Δε / (1 + (jω/ωc)^(1-α))
```
- `α`:  Cole-Cole 指数 (0 < α < 1)

**Davidson-Cole 模型**:
```
ε(ω) = εh + Δε / (1 + jω/ωc)^β
```
- `β`: Davidson-Cole 指数 (0 < β ≤ 1)

**Havriliak-Negami 模型**:
```
ε(ω) = εh + Δε / (1 + (jω/ωc)^(1-α))^β
```
- `α`: 描述对称展宽
- `β`: 描述不对称展宽

### 球壳结构字段

```json
"shell_structure": [
  {
    "layer": 1,
    "layer_name": "Core",
    "modeltype": "Db",
    "parameters": {
      "epsh": { "init": 10.0, "min": 0.0, "max": 100.0 },
      "Deps": { "init": 100.0, "min": 0.0, "max": 1000.0 },
      "Tao": { "init": 1e-9, "min": 1e-12, "max": 1e-2 }
    }
  },
  {
    "layer": 2,
    "layer_name": "Shell",
    "modeltype": "CC",
    "parameters": {
      "epsh": { "init": 10.0, "min": 0.0, "max": 100.0 },
      "Deps": { "init": 50.0, "min": 0.0, "max": 1000.0 },
      "Tao": { "init": 1e-6, "min": 1e-12, "max": 1e-2 },
      "Alpha": { "init": 0.3, "min": 0.0, "max": 1.0 }
    }
  }
]
```

### 介质参数 (media)

```json
"media": {
  "Eps": 80.0,
  "Sigma": 0.001,
  "phi": 0.05,
  "mixture_model": "auto"
}
```

| 参数 | 说明 | 典型值 |
|-----|------|-------|
| Eps | 介质相对介电常数 | 80 (水) |
| Sigma | 介质电导率 (S/m) | 0.0 ~ 1.0 |
| phi | 颗粒体积分数 | 0.01 ~ 0.5 |
| mixture_model | 混合物模型 | Maxwell/Hanai/auto/none |

### mixture_model 选项

| 选项 | 说明 |
|-----|------|
| `none` | 纯颗粒，无混合物模型 |
| `Maxwell` | Maxwell 混合物模型（适用于 phi < 0.1） |
| `Hanai` | Hanai 混合物模型（适用于 phi > 0.1） |
| `auto` | 根据 phi 自动选择 |

## MT 模型 (多项介电模型)

MT 模型用于描述具有多个介电弛豫过程的材料，如生物组织、高分子聚合物等。

### 文件位置
```
ModelFileExamples/MT/MT_Debye.json          # 单Debye模型
ModelFileExamples/MT/MT_DoubleDebye.json    # 双Debye模型
ModelFileExamples/MT/MT_ColeCole.json       # Cole-Cole模型
ModelFileExamples/MT/MT_DavidsonCole.json   # Davidson-Cole模型
ModelFileExamples/MT/MT_HavriliakNegami.json # Havriliak-Negami模型
```

### 支持的模型类型

| 模型类型 | 代码 | 说明 |
|---------|------|------|
| Debye | Db | 单个Debye弛豫过程 |
| Cole-Cole | CC | Cole-Cole色散模型 |
| Davidson-Cole | DC | Davidson-Cole色散模型 |
| Havriliak-Negami | HN | HN色散模型 |

### 完整文件结构

```json
{
    "version": "1.0",
    "model_type": "MT",
    "model_name": "Double_Debye",
    "file_path": "",
    "created_date": "2026-06-15",
    "frequency": {
        "min": 10.0,
        "max": 1000000000.0,
        "distribution": "Log",
        "unit": "Hz"
    },
    "option": {
        "EP": 0,
        "DC Conductivity": 1
    },
    "model_terms": [
        {
            "name": "1",
            "modeltype": "Debye",
            "expression": "Deps1/(1+j*omega*Tao1)"
        },
        {
            "name": "2",
            "modeltype": "Debye",
            "expression": "Deps2/(1+j*omega*Tao2)"
        }
    ],
    "parameters": [
        {
            "name": "epsh",
            "init": 10.0,
            "min": 0.0,
            "max": 100.0
        },
        {
            "name": "sigmaDC",
            "init": 1e-4,
            "min": 0.0,
            "max": 1.0
        },
        {
            "name": "Deps1",
            "init": 50.0,
            "min": 0.0,
            "max": 200.0
        },
        {
            "name": "Tao1",
            "init": 1e-5,
            "min": 1e-12,
            "max": 1e-2
        },
        {
            "name": "Deps2",
            "init": 30.0,
            "min": 0.0,
            "max": 200.0
        },
        {
            "name": "Tao2",
            "init": 1e-7,
            "min": 1e-12,
            "max": 1e-2
        }
    ]
}
```

### model_terms 字段说明

| 字段 | 类型 | 说明 |
|-----|------|------|
| `name` | string | 项编号（1, 2, 3...） |
| `modeltype` | string | 模型类型：Debye/Cole-Cole/Davidson-Cole/Havriliak-Negami |
| `expression` | string | 介电响应表达式，使用 omega 表示角频率 |

### model_terms 表达式示例

**Debye 项**:
```
Deps1/(1+j*omega*Tao1)
```

**Cole-Cole 项**:
```
Deps1/(1+(j*omega*Tao1)^(1-Alpha1))
```

**Davidson-Cole 项**:
```
Deps1/(1+j*omega*Tao1)^Beta1
```

**Havriliak-Negami 项**:
```
Deps1/(1+(j*omega*Tao1)^(1-Alpha1))^Beta1
```

### 全局参数

每个 MT 模型都包含以下全局参数：

| 参数名 | 说明 | 典型值范围 |
|-------|------|------------|
| `epsh` | 高频介电常数（电极化贡献） | 0 ~ 100 |
| `sigmaDC` | 直流电导率 | 0 ~ 1.0 S/m |

### 项参数

每个 model_term 对应以下参数：

| 参数名 | 说明 | 适用模型 |
|-------|------|---------|
| `Deps` | 弛豫强度 (Δε) | 所有模型 |
| `Tao` | 弛豫时间 (τ) | 所有模型 |
| `Alpha` | Cole-Cole/HN指数 (0<α<1) | Cole-Cole, HN |
| `Beta` | Davidson-Cole/HN指数 (0<β≤1) | Davidson-Cole, HN |

### 选项 (option)

| 选项 | 说明 | 值 |
|-----|------|-----|
| `EP` | 电极化效应 | 0=不考虑, 1=考虑 |
| `DC Conductivity` | 直流电导率 | 0=不考虑, 1=考虑 |

## 文件命名规范

建议按以下格式命名：
```
{模型类型}_{描述}.json
```

**示例**：
- `ECM_Randles.json` - Randles等效电路
- `ECM_Double_Randles.json` - 双Randles电路
- `MT_Debye.json` - 单Debye弛豫模型
- `MT_DoubleDebye.json` - 双Debye弛豫模型
- `MT_ColeCole.json` - Cole-Cole模型
- `MT_DavidsonCole.json` - Davidson-Cole模型
- `MT_HavriliakNegami.json` - Havriliak-Negami模型
