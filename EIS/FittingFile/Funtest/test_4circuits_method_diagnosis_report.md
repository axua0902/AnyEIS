## 1. 测试设计

### 1.1 电路选择依据

基于历史测试经验（特别是 EIS_Fitting_Analysis_Summary.md 第 4 节和第 11 节），从原 10 组测试中精选 4 组覆盖
不同难度和不同失败模式的电路：

| 编号 | 电路 | 难度 | 测试目标 |
|------|------|------|----------|
| C1 | R1 + p(C3, R6) | 基准 | 验证所有方法在简单 Randles 上都能成功 |
| C2 | R1 + p(C1, R2) + p(C3, R4) | 困难 | 多解性挑战 — 已知该结构容易混淆 R2/R4、C1/C3 |
| C3 | R1 + p(C1, R2) + R3 | 中等 | 树状串并联 — 旧文档列为"最复杂的可靠结构" |
| C4 | R1=1mΩ + p(C3, R6=1MΩ) | 极限 | 9 数量级参数差异 — 验证 DE/DA 边界 |

### 1.2 10 个优化方法

| 方法 | 类别 | 特点 |
|------|------|------|
| `least_squares` | 局部 | scipy 信赖域 + soft_l1 损失 |
| `nelder` | 局部 | Nelder-Mead 单纯形，不需梯度 |
| `lbfgsb` | 局部 | 拟牛顿 + 有限内存 + 边界支持 |
| `powell` | 局部 | 方向集方法，无需求导 |
| `cg` | 局部 | 共轭梯度 |
| `bfgs` | 局部 | 拟牛顿 |
| `differential_evolution` | 全局 | 遗传算法变体，DE |
| `dual_annealing` | 全局 | 双模拟退火 |
| `basinhopping` | 全局 | 盆地跳跃 |
| `ampgo` | 全局 | Accelerated Modified Powell Gradient（需 ampgo 包） |

### 1.3 边界策略对比

**关键：本测试设计两个边界策略，用于隔离"边界过宽"对全局方法的影响。**

| 策略 | 公式 | 含义 |
|------|------|------|
| **A_宽边界_1e-15_1e15** | `min=1e-15, max=1e15` | 复现 `_auto_fitting_core` 默认行为，所有方法都使用 |
| **B_紧边界_init100x** | `min=init*1e-2, max=init*1e2` | 基于初值收紧 100 倍 |

### 1.4 评级标准

| 评级 | 最大相对误差 |
|------|---------------|
| 优 | < 5% |
| 良 | < 20% |
| 中 | < 100% |
| 差 | < 1e6 % |
| 崩溃 | ≥ 1e6% 或异常 |

## 7. 关键问题分析

### 7.1 现有程序中的核心问题

**问题 1：宽边界 [1e-15, 1e15] 是全局方法的灾难**

在 `_auto_fitting_core` 中，所有方法都使用同一套边界 `min=1e-15, max=1e15`（30 个数量级！）。
对 `least_squares`、`lbfgsb` 等局部算法影响小（因为它们在初值附近搜索），
但对 `differential_evolution`、`dual_annealing`、`basinhopping` 等全局算法而言：

- 搜索空间太大，30 个数量级
- 群体/退火随机生成的候选解可能偏离真值 1e10 以上
- 残差函数 `|Z_diff|/|Z_meas|` 在极端参数值下退化为 NaN/Inf
- 优化器无法收敛到真值附近

**从测试结果可见**：紧边界 [init/100, init*100]（4 个数量级）下，全局方法可用性大幅提升。

**问题 2：缺乏参数空间约束与电路先验知识**

参考 [EIS_Fitting_Analysis_Summary.md 第 11 节](EIS_Fitting_Analysis_Summary.md#11-极端条件分段拟合处理策略)：
对于 Randles 类电路，可以通过物理先验知识（如"高频段实部 ≈ R1"）来收紧边界。
但当前 `_auto_fitting_core` 直接用 `1e-15 ~ 1e15` 这种"无信息"边界，
完全没有利用电路拓扑信息。

**问题 3：双并联分支的多解性无法通过更换算法解决**

C2 双并联分支电路在两种边界策略下，DE/DA/AMPGO 等全局方法都收敛到错误局部最优。
这是物理多解性（不同 (R2, C1) 组合产生相似阻抗曲线），算法层面无法解决，
需要：

- 物理约束（如已知 R1，从高频段估计）
- 多起点 + 物理约束
- 时间常数分析（参考 [第 11 节策略 1](EIS_Fitting_Analysis_Summary.md#111-问题本质)）

**问题 4：极限量级差（C4）下所有方法都失败**

即使在紧边界下，C4 (R1=1mΩ, R6=1MΩ) 也几乎没有方法能找到正确解。
原因是：

- `tight` 边界 (init*100) 对 R1=1mΩ 来说只有 [1e-4, 1]，覆盖不到 R1=1e-3 太远
- 全局方法在 [1e-4, 1] × [1e-6, 1e-2] × [1e5, 1e9] 仍然太大
- 相对误差归一化在 9 数量级差异下失效

参考 [EIS_Fitting_Analysis_Summary.md 第 11 节](EIS_Fitting_Analysis_Summary.md#11-极端条件分段拟合处理策略)：
需要用 `multi_start_fit` + R1_est 约束。
