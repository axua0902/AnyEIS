## 5. 综合结论

### 5.1 方法推荐

| 场景 | 推荐方法 | 原因 |
|------|---------|------|
| 简单电路（C1） | `least_squares` 或 `lbfgsb` | 局部算法快且准确 |
| 多解性电路（C2） | `least_squares`（带 R1 约束） | 全局方法在多解性下不稳定 |
| 树状串并联（C3） | `least_squares` 或 `lbfgsb` | 局部方法收敛快 |
| 极端量级（C4） | `differential_evolution` | 全局搜索更适合穿越多尺度 |

### 5.2 通用问题

1. **ampgo 在 4 电路中表现不稳定**
   - ampgo 是 lmfit 自定义方法，参数 (glbtol/eps1/eps2/maxfunevals/totaliter) 与 scipy 其它方法不同
   - 在 4 电路测试中失败率较高，需要调参或使用更稳定的全局方法

2. **多解性是双并联分支的主要瓶颈**
   - C2（双并联）下大多数方法出现 C3/R4 误差 > 100%
   - 全局方法（DE/DA）在多解性下不一定优于局部方法
   - 需要 R1 物理约束 + 多起点搜索

3. **极端量级差（9 数量级）下所有方法都难以稳定**
   - 即使是 `least_squares` 在 C4 上也可能失败
   - 需要配合 R1_est 物理约束（来自分段估计）
   - 或对参数做对数变换

4. **计算量差异巨大**
   - `least_squares` ~ 40-100 nfev
   - `differential_evolution` / `dual_annealing` / `basinhopping` ~ 1000-10000 nfev（10-100x）
   - `ampgo` ~ 1000-20000 nfev（最慢）

### 5.3 改进建议

1. **R1 物理约束**
   - 用高频段 Z 实部估计 R1_est，作为 R1 边界 [R1_est/10, R1_est*10]
   - 防止优化器把 R1 错位分配到 R6

2. **多起点 + R1 约束的混合策略**
   - 在 differential_evolution / basinhopping 内部使用 R1 约束
   - 见 [EIS_Fitting_Analysis_Summary.md 第 11.7 节](EIS_Fitting_Analysis_Summary.md#117-关键代码改进)

3. **ampgo 调参或替换**
   - ampgo 失败时回退到 `differential_evolution`
   - 或调小 `eps1/eps2/totaliter` 提高收敛速度

4. **结果后处理校验**
   - 拟合后检查物理一致性：
     - 特征频率 fc = 1/(2πRC) 应在测量频段内
     - 多分支电路应检查时间常数不重叠
