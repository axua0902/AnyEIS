# EIS 等效电路拟合问题分析与解决方案总结

## 1. 问题背景

在 EIS（电化学阻抗谱）等效电路拟合过程中，遇到以下问题：
- `UnboundLocalError: cannot access local variable 'workbook'`
- `TypeError: NAN/INF not supported in write_number()`
- 拟合结果出现 NaN/Inf
- 参数量级差异大（mΩ ~ MΩ）导致拟合失败
- 初始猜测远离真实值时拟合崩溃
- 多元件复杂电路拟合崩溃

## 3. 残差函数方法对比

### 3.1 测试的方法

| 方法 | 残差函数公式 | 结果 |
|------|-------------|------|
| 方案1 | `abs((Zcalc-Zmeas)/Zmeas)` | ❌ 始终失败 |

### 4.3 关键发现

**1. 电路结构对拟合稳定性影响巨大**

| 电路结构 | 典型案例 | 结果 |
|---------|---------|------|
| 纯串联 | 测试1,2,5 | 全部优秀（<0.3%） |
| 单并联 | 测试3 | 一般（20%误差） |
| 串并联混合 | 测试4 | 良好（6%误差） |
| 多并联分支 | 测试6-9 | **崩溃（误差千万倍）** |

**2. 多解性问题是复杂电路的主要瓶颈**

- 当存在多个RC并联组合时，不同参数组合可能产生相似的阻抗曲线
- 优化器无法区分正确解和错误解
- 测试6: R2=100Ω//C1=1µF 与 C2=0.1µF串联 → 优化器混淆

**3. 参数量级差异导致归一化失效**

- 测试10: R从1mΩ到1MΩ（9数量级差异）
- 相对误差归一化在极端量级下失效
- R1误差达96211%

**4. 串联电路表现稳定的原因**

- 阻抗计算是累加的，各参数对总阻抗的贡献是独立的
- 优化器可以逐步调整每个参数

## 5. 最佳方案

### 5.1 推荐：相对误差归一化（方法4）

```python
def fcn2min(params, freq, circuit, ZDataTest):
    """相对误差归一化残差函数"""
    Ztotal, Zparallel = simuECM(params, circuit, freq)
    denom = np.abs(ZDataTest) + 1e-10  # 防止除零
    Z_diff = (Ztotal - ZDataTest) / denom
    resid = np.abs(Z_diff)
    return resid
```

**优点**：
- 在温和条件下所有参数误差 < 3%
- 能有效消除参数量级差异的影响
- 实现简单，稳定可靠

**适用条件**：
- 电路元件数量 ≤ 3
- 参数数量级差异 ≤ 5个数量级
- 频率跨度 ≤ 6个数量级

### 8.1 分步拟合策略
- **先串后并**：先拟合串联赛部分，再处理并联部分

## 11. 极端条件分段拟合处理策略

### 11.1 问题本质

当 τ = RC 很大或很小时，特征频率 fc = 1/(2πRC) 可能不在测量频率范围内：

| 情况 | 条件 | 物理表现 | 拟合挑战 |
|------|------|----------|----------|
| **R6不可见** | fc < f_min | 低频段电容开路，Z ≈ R1+R6（串联） | 无法独立确定R6 |
| **C3不可见** | fc > f_max | 高频段电容短路，Z ≈ R1 | 无法独立确定C3 |
| **参数可见** | f_min < fc < f_max | 全频段可观测 | 标准拟合即可 |

### 11.2 四大处理策略

#### 策略1：参数可辨识性检查

```python
def check_parameter_identifiability(freq, R6, C3, r1=10.0, margin=10.0):
    """
    检查参数在测量范围内是否可辨识

    返回:
        'visible'      - fc在测量范围内
        'R6_invisible' - fc < f_min/margin，R6不可见
        'C3_invisible' - fc > f_max*margin，C3不可见
    """
    f_min, f_max = freq.min(), freq.max()
    tau = R6 * C3
    f_char = 1 / (2 * pi * tau)

    if f_char < f_min / margin:
        return 'R6_invisible', f_char
    elif f_char > f_max * margin:
        return 'C3_invisible', f_char
    else:
        return 'visible', f_char
```

#### 策略2：自适应分段

```python
def adaptive_segmentation(freq, ZData, f_char):
    """
    基于特征频率的自适应分段

    高频阈值 = f_char * 10
    低频阈值 = f_char / 10
    """
    f_min, f_max = freq.min(), freq.max()
    high_threshold = min(f_char * 10, f_max)
    low_threshold = max(f_char / 10, f_min)

    high_mask = freq > high_threshold
    mid_mask = (freq >= low_threshold) & (freq <= high_threshold)
    low_mask = freq < low_threshold

    # R1估计：高频段实部均值
    R1_est = np.mean(real(ZData[high_mask])) if np.sum(high_mask) >= 3 else np.mean(real(ZData[-3:]))

    # R6估计：低频段实部减去R1
    if np.sum(low_mask) >= 3:
        R6_est = np.mean(real(ZData[low_mask])) - R1_est
    else:
        R6_est = None

    # C3估计：特征频率处的阻抗虚部
    if np.sum(mid_mask) > 0:
        idx_closest = np.argmin(np.abs(freq[mid_mask] - f_char))
        Z_imag = imag(ZData[mid_mask][idx_closest])
        C3_est = -1 / (2 * pi * f_char * Z_imag) if Z_imag < 0 else None
    else:
        C3_est = None

    return R1_est, R6_est, C3_est
```

#### 策略4：多起点全局搜索

```python
def multi_start_fit(freq, ZData, circuit, n_starts=10):
    """
    在对数空间均匀采样多个起始点，避免局部最优
    """
    best_result = None
    best_error = float('inf')

    for _ in range(n_starts):
        # 对数空间均匀采样
        R1_init = 10 ** np.random.uniform(-3, 6)   # 1e-3 ~ 1e6
        C3_init = 10 ** np.random.uniform(-12, 2)  # 1e-12 ~ 100
        R6_init = 10 ** np.random.uniform(0, 9)    # 1 ~ 1e9

        pm = Parameters()
        pm.add('R1', value=R1_init, min=1e-6, max=1e8)
        pm.add('C3', value=C3_init, min=1e-12, max=1e4)
        pm.add('R6', value=R6_init, min=1e-3, max=1e12)

        result = Minimizer(fcn2min, pm, fcn_args=(freq, circuit, ZData),
                          loss='soft_l1', max_nfev=1e5).minimize()

        error = fcn2min(result.params, freq, circuit, ZData)
        if error < best_error:
            best_error = error
            best_result = result

    return best_result
```

- **改进后**：加入 R1_est 物理约束后，C3=119pF, R6=100Ω（误差0.31%）
- **核心方法**：用自适应分段估计的 R1_est 作为约束边界
- **进一步改善**：扩展低频测量范围（如1MHz~10GHz）

### 11.4 策略选择指南

```
┌─────────────────────────────────────────────────────────────────┐
│  1. 先检查参数可辨识性                                           │
│     check_parameter_identifiability(freq, R6, C3)              │
│                                                                  │
│  2. 根据情况选择策略：                                           │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │ 情况                     │ 推荐策略                        │  │
│  ├────────────────────────────────────────────────────────────┤  │
│  │ fc 在测量范围内          │ 多起点搜索 + R1_est 约束       │  │
│  │ fc < f_min (R不可见)     │ 约束优化 + 宽边界 R6           │  │
│  │ fc > f_max (C不可见)     │ 固定C + 多起点搜索 R1/R6       │  │
│  │ fc 靠近f_min或f_max      │ R1_est强约束 + 更多起点        │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  3. 多起点搜索参数范围（对数空间）：                            │
│     R1: R1_est × 0.1 ~ R1_est × 10 （R1约束）                   │
│     C3: 1e-12 ~ 100 F                                          │
│     R6: 1 ~ 1e9 Ω                                              │
│     建议至少30个起点                                            │
│                                                                  │
│  4. R1_est 约束的来源：                                          │
│     使用 adaptive_segmentation 得到的高频段 R1 估计值            │
│     边界: [R1_est × 0.1, R1_est × 10]                          │
│     作用: 防止 R1 被优化器错位分配到 R6                          │
└─────────────────────────────────────────────────────────────────┘
```

### 11.5 核心原则

1. **先检查，再拟合** - 使用 `check_parameter_identifiability` 判断情况
2. **R1 物理约束** - 用自适应分段估计的 R1_est 约束多起点搜索边界
3. **扩展低频测量范围** - 解决 R6 不可见和边缘多解性的根本方法
4. **接受不确定性** - 当 R6 不可见时，报告结果需说明 R6 的不确定性
5. **多起点搜索** - 建议使用 ≥30 个起点，配合 R1_est 约束避免局部最优

### 11.6 适用条件总结

| 方法 | 频率跨度 | 参数数量级差异 | 元件数量 | 成功率 |
|------|----------|---------------|----------|--------|
| 标准拟合 + 相对误差归一化 | ≤6数量级 | ≤5数量级 | ≤3 | >90% |
| 多起点搜索 + R1约束 | 7-10数量级 | 5-8数量级 | ≤5 | >85% |
| 约束优化 + 宽边界 | >10数量级 | >8数量级 | ≤3 | >50% |
| 自适应分段 + 多起点 | 任意 | 任意 | 3 | >80% |

### 11.8 警告与局限性

1. **R6 不可见时**：
   - R6 误差 96% 是**正常的、预期的**
   - 这是因为低频数据无法提供足够的 R6 信息
   - **强行估计会导致严重误差**，应使用宽边界并报告不确定性
   - 扩展低频测量范围（mHz级别）是根本解决方法

2. **C3 不可见时**：
   - **存在多解性**：R1 和 R6 的不同组合可能产生相似的阻抗曲线
   - 场景C测试中 R1 误差 22.5% 说明了这一问题
   - 使用多起点搜索可以缓解，但无法完全消除
   - **物理本质**：当 fc >> f_max，电容在测量频段不表现为短路

3. **边缘可见情况 (fc靠近f_min或f_max)**：
   - 存在**物理多解性**：不同 (C3, R6) 组合产生相似阻抗
   - 改进方案：**R1_est 物理约束**（R1 边界 = R1_est × [0.1, 10]）
   - 改进效果：场景D的 R6 误差从 2978% 降至 0.31%
   - 进一步改善：扩展低频测量范围

4. **多起点搜索的局限性**：
   - 当存在多解性时，多起点可能收敛到不同的局部最优
   - 需要结合物理先验知识（如 R1_est 约束）来选择正确解

### 13.3 3并联分支电路测试结果

**测试电路**: R1 + p(R2,C2) + p(R3,C3) + p(R4,C4)

| 参数 | 真实值 | LMFIT误差 | DE误差 | DA误差 |
|------|--------|-----------|--------|--------|
| R1 | 100Ω | **0.1%** | 0.0% | 0.0% |

| C3 | 100nF | 11.0% | **900%** | 11.9% |
| R4 | 200Ω | **3.6%** | **463%** | 62.5% |
| C4 | 500nF | 85.4% | 82.3% | **192%** |

### 13.4 关键发现

**1. LMFIT + soft_l1 是最稳定的选择**

- 即使在受控条件下，多解性问题依然存在
- 对R1的估计始终最准确（<1%误差）
- 对后端并联分支（C4）的估计最差（85%误差）
- 原因：后端元件对总阻抗的"可见性"较低

**2. 全局优化算法（DE/DA）表现不稳定**

- 部分参数优秀（R2/DA: 0.9%），部分极差（C3/DE: 900%）
- 全局搜索在复杂电路上不一定优于局部优化
- 计算量大（~10-100倍于LMFIT）

**3. 并联分支位置影响拟合质量**

```
前端并联分支 (R2,C2) → 误差较小
中端并联分支 (R3,C3) → 误差中等
后端并联分支 (R4,C4) → 误差最大
```

### 13.5 8元件混合串并联测试结果

**测试电路**: R1 + p(R2,C2) + R3 + p(R4,C4) + R5

| 算法 | 最大误差 | 评价 |
|------|----------|------|
| LMFIT + soft_l1 | <15% | 良好 |
| 差分进化 (DE) | <30% | 一般 |
| 分级拟合 | <20% | 良好 |

**结论**：树状串并联结构（避免并联-并联堆叠）拟合效果明显更好

### 13.6 核心结论

**算法选择建议**：

| 场景 | 推荐算法 | 原因 |
|------|---------|------|
| 简单电路（≤3元件） | LMFIT + soft_l1 | 快速、准确 |
| 复杂电路（>3元件） | LMFIT + soft_l1 + 窄边界 | 全局算法不稳定 |
| 树状串并联结构 | 分级拟合 + LMFIT精修 | 利用物理特性 |
| 避免使用 | 纯DE/DA全局优化 | 多解性导致不稳定 |

**多解性问题的本质**：

```
3并联分支电路的物理多解性：

不同的 (R,C) 组合可能产生几乎相同的阻抗曲线

例如：τ1 = R2×C2 = 500×1e-6 = 5e-4
      τ2 = R3×C3 = 1e3×1e-7 = 1e-4
      τ3 = R4×C4 = 200×5e-7 = 1e-4

当 τ2 ≈ τ3 时，优化器无法区分 C3 和 C4 的贡献
```

**对于15元件电路的建议**：

1. **必须采用树状串并联结构**：
   ```
   推荐: R + p(R,C) + R + p(R,C) + R + p(R,C) + R + ...
   避免: R + p(R,C) + p(R,C) + p(R,C) + ... (并联堆叠)
   ```

2. **确保特征频率分布合理**：
   - 每个RC并联的特征频率 fc = 1/(2πRC) 应在测量频段内
   - 相邻并联分支的 fc 应相差至少2个数量级

3. **使用分级拟合策略**：
   - 高频估计R1 → 低频估计R_total → 中频段估计各并联分支
